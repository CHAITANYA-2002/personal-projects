04The two findings worth defending

The elevation confounder

An early model put elev_mean top of the SHAP ranking at 2.3× the runner-up. The cause was the hill mask one stage removed: slope_mean ≥ 5° admits the Ladakh and Tibetan plateau, so background controls sat at 4,479 m against 1,433 m for cases. The model was separating a plateau from a slope.

Fixed by elevation-band matching in the sampler — gap now −17 m, elev_mean absent from the top 15. The finding has since survived a change of model and a tripling of the data.

Say this correctly

The PR-AUC before and after is not comparable — different sample, different test split. Only the SHAP ranking is a fair before/after. Claiming a metric improvement there would be exactly the dishonesty the rest of the system is built to prevent.

The base rate moved, and the model did not get worse

The headline PR-AUC fell 0.410 → 0.244 between runs. The base rate fell with it, 0.267 → 0.168. Lift went 1.54× → 1.45×, and everything base-rate independent improved:

06Traps — do not rediscover these

TrapWhat happens
Never compare two PR-AUCs directlyThe test split grows with the backfill. Read the lift over the base rate, and the bootstrap interval, or you will report a change that did not occur.
The forecast path has no cacheA --dry-run of 08_score.py costs the same quota as a real run. Doing the dry run first consumed the very attempt it was protecting — the real run got 0 cells 25 seconds later. Trust the weather.empty guard, which returns before the delete, and run it live.
Streamlit caches survive a re-scoreEvery loader now takes data_version(). Add that argument to any new cached loader or it will serve stale predictions for up to an hour after the next score.
fetch_forecast never charges the budget_budget.json understates real spend, sometimes badly. It is a guideline, not the truth. HTTP 429 is the truth.
dim_date is not a pure dimension08_score.py appends forecast days to it. Anything reading it unbounded inherits future dates. Two readers were bitten; both are now clamped and tested.
Never open the catalogue CSV in ExcelIt rewrites 4,395 of 11,033 dates to DD-MM-YYYY. 4,083 events would be misdated under either convention. dataset/ holds the corrupted copy; the code reads data/raw/.
Grep for "Power BI" with the spaceA sweep for powerbi missed 17 references. Power BI is now fully removed except inside the banner-marked historical plan.
git add -A from this directorySweeps in the unrelated sibling project capstone -powerbi. Stage explicit paths.
Figures must reproduce their metricThe first version of 14_report_figures.py skipped calibration and drew recall@5% as 0.117 against 0.130 in the JSON. It now asserts agreement before drawing.

Honest scope note

The learning curve has flattened, so more training data will not move the score much. The remaining ceiling is predictor resolution: daily rainfall sums on an 11 km grid cannot see the three-hour burst that tips a saturated slope. The intensity-duration gate passes, so the data does resolve duration and antecedent build-up — it is specifically the sub-daily axis that is missing. That is the narrower, defensible claim.
